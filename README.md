# 小小水果铺 · Unit 3 Lesson 1

供成人陪伴、课堂演示和儿童触摸探索使用的静态英语互动样板。发布目标仅为 GitHub Pages。不依赖服务器、账号、数据库、外部字体或在线 AI。

## 教学范围

- orange、grapes；watermelon、apple、banana。按两组学习，可切换五词回顾。
- 看一看：点击水果听发音，教师可以播放、暂停、继续和重播。
- 点一点：听词选图，先二选一，再增加到三选一。允许重听、提示和重试。
- 玩一玩：按语音提示把水果放入篮子，完成后鼓励；没有倒计时或扣分。
- 教师扩展：通过一个苹果、两个苹果的数量变化示范 There’s / There are。口语由教师观察，不进行自动发音评分。

## 使用

打开发布网址，选择教师模式或儿童模式。声音由第一次点击启动。教师模式可选择词组、教学活动、暂停或继续语音、重播与显示提示。儿童模式收起教师面板，保留大图和重听按钮。

网站不收集姓名、声音或个人信息，不申请麦克风权限。练习状态只保留在当前页面，刷新后重置。

离线使用：下载仓库中的 `index.html`，直接用浏览器打开。所有运行所需插画和发音均嵌入此文件；首次访问在线站点仍需要网络，网站没有承诺自动离线缓存。

## 发布

GitHub 仓库 Settings → Pages → Deploy from a branch → main → /(root)。入口为 index.html，无需构建工具。请在成都实际课堂网络、电脑和平板上检查首次加载与发音播放。

## 资产与限制

参见 ASSETS.md。插画为本项目新生成，语音为合成示范，不是教材原声。正式教学前应由教师复核示范发音。当前站点不附带教材扫描页、教材角色、歌曲或商业音视频。
